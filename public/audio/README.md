缺檔時的行為：

- 注音：Popup 仍顯示符號並註明「尚未加入發音音檔」，**不會**改用瀏覽器 TTS（避免念錯）。
- 鼓勵語：若裝置有中文語音，使用 Web Speech API 念出鼓勵句；沒有就只顯示文字。
- 任何情況都不會讓互動卡住。
